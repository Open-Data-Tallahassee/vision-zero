# Coverage report

Generated by `website/scripts/build-crash-data.mjs`. Do not edit by hand. Rerun with `npm run data:build` from `website/`.

## Sources

- Crashes: `data/leon-county-crashes/map/leon-county-crashes.geojson` (12743 records). Florida Department of Highway Safety and Motor Vehicles (FLHSMV) crash records, Leon County.
- People: `data/leon-county-crashes/2020/processed/2020_202412251425.csv` and `data/leon-county-crashes/2021-q1-and-q2/processed/2021-q2_202412251115.csv`. One row per person on a crash report, with role and injury severity.
- Street names: `data/clean/all-2018to2021.csv`.
- Boundaries: U.S. Census Bureau TIGERweb, January 1, 2021 vintage (Leon County GEOID 12073; Tallahassee city GEOID 1270600). Files in `data/boundaries/`.
- Code meanings: `data/docs/person-code-dictionary.md` and `data/docs/events-code-dictionary.md`, transcribed from the FLHSMV crash data dictionary.

## Coverage window

2020-01-01 to 2021-06-30. The source file has only scattered records before 2020, so earlier dates are excluded rather than shown as if those years were covered. Nothing after 2021-06-30 has been collected yet.

## What this data cannot show yet

- **Completeness.** Whether every quarter is complete hasn't been checked against FLHSMV totals. 2020 Q2 is noticeably lower, which is consistent with reduced travel in spring 2020 but hasn't been confirmed.
- **Injury severity before 2020.** Person-level records exist only for this window (and a separate April to June 2019 file that isn't used here).
- **City limits over time.** The 2021 city boundary is applied to all crashes.
